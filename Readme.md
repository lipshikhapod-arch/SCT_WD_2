# ⏱️ Stopwatch Web App

A responsive and interactive **Stopwatch Web Application** developed using **HTML, CSS, and JavaScript**.

## 📌 About the Project

This project was developed as part of my **SkillCraft Technology Web Development Internship**.

The objective of this task was to develop a functional and user-friendly stopwatch application that allows users to accurately measure elapsed time through simple and interactive controls.

## ✨ Features

* ▶️ **Start** — Starts the stopwatch and begins tracking elapsed time.
* ⏸️ **Pause** — Pauses the stopwatch while preserving the elapsed time.
* 🔄 **Reset** — Resets the stopwatch to its initial state.
* ⏱️ **Real-Time Display** — Displays the elapsed time dynamically.
* 📱 **Responsive Design** — Adapts to different screen sizes and devices.
* 🎨 **Clean User Interface** — Provides a simple and visually appealing interface.
* 🖱️ **Interactive Controls** — Allows users to easily control the stopwatch.

## 🛠️ Technologies Used

* **HTML5** — Used to structure the application.
* **CSS3** — Used for styling, layout, animations, and responsive design.
* **JavaScript** — Used to implement the stopwatch functionality and user interactions.

## ⚙️ How It Works

The stopwatch uses JavaScript to calculate and display the elapsed time.

* **Start** begins the timer.
* **Pause** stops the timer while maintaining the current elapsed time.
* **Reset** clears the elapsed time and returns the stopwatch to its initial state.

The interface is designed using HTML and CSS to provide a responsive and user-friendly experience.

## 🚀 How to Run the Project

1. Clone this repository to your computer.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Use the Start, Pause, and Reset controls to operate the stopwatch.
